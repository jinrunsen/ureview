# AGENTS.md

这棵树放文档。四条规则：

- **一件事只有一个家。** 架构在 `architecture.md`，测试策略在 `testing.md`，词汇在 `glossary.md`。同一个事实写在两处，必然漂移。写之前先想它该属于谁。
- **写现状，不写过程。** 文档说系统现在是什么样，不说它怎么变成这样的——那是 [Agent Note](../.agents/notes/README.md) 的活。不要保留评审历史，不要复述代码。
- **存量事实带 `source:`。** 接口路径、错误码、字段名、实测数值、容量与性能现状，一律行内括注出处，指向 Agent Note 或 [research/](research/)。本次新做的决定不带锚点——它现在才产生。
- **`research/` 是一手材料，只增不改。** 调研原件与真实产品素材放在这里，它们是被引用的证据；结论属于引用它们的文档。
