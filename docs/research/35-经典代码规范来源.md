# 经典代码规范来源

2026-10-05 为 [R36 经典规范库](../../requirements/01-v1-qodo-reproduction/story-map.md#十三迭代-4-起点)做的一手调研：收录候选清单、收录标准与许可边界。许可结论以各来源的 LICENSE 或版权页为准，下表记录检索当日看到的内容。

## 收录标准

编辑精选，满足下列至少两条：

- 出版成书，或由标准组织、知名机构正式发布。
- 社区引用和使用热度高：GitHub 星数、被 linter 实现、被教材和课程引用。
- 持续使用多年，仍在维护或仍被引用。
- 被知名大型项目或机构采纳为强制规范。

## 许可分档

许可决定收录形态，不决定是否值得推荐。

| 档 | 收录形态 | 例 |
|---|---|---|
| 开放 | 可收录条文并改写，署名、附许可 | Google 风格指南与 eng-practices（CC-BY 3.0）、Uber Go 风格指南（Apache 2.0）、阿里巴巴 Java 开发手册所在仓库（Apache 2.0，PDF 本身的版权页待核） |
| 内部可用 | 只做自写要点和出处链接，不收录原文 | C++ Core Guidelines（许可限个人或内部使用）、SEI CERT C/C++（对外复制需授权）、Linux 内核与 DPDK 编码风格（GPL / BSD 文档，随源码分发） |
| 受版权保护 | 只做自写要点、书名与章节出处 | 《重构》、《C 陷阱与缺陷》等书籍 |
| 需授权 | 只列名称与链接，不写条文 | MISRA C（单人付费许可，条文受版权保护，工具内使用条文需另行授权） |

原则类条目（KISS、奥卡姆剃刀等）没有单一版权方，自写表述并注明出处即可。

## 候选清单

按[规范分层](../../requirements/01-v1-qodo-reproduction/15-rule-hierarchy/story.md)的原则层、通用层、语言层归类。「依据」列对应上面的收录标准。

### 原则层

| 条目 | 来源 | 依据 |
|---|---|---|
| KISS、YAGNI、DRY | 工程界通行原则；DRY 出自《程序员修炼之道》 | 长期通行、被书籍收录 |
| 奥卡姆剃刀 | 哲学原则，用于设计取舍 | 长期通行 |
| SOLID | Robert C. Martin | 出书、教材通用 |
| 迪米特法则（最少知识） | 1987 年 Demeter 项目 | 长期通行 |
| Unix 哲学 | McIlroy、《Unix 编程艺术》 | 出书、长期通行 |
| Python 之禅（PEP 20） | Python 官方，公有领域 | 官方发布 |
| 童子军规则、切斯特顿栅栏 | 《代码整洁之道》、G. K. Chesterton | 出书、长期通行 |

### 通用层（跨语言）

| 条目 | 来源 | 依据 | 许可档 |
|---|---|---|---|
| 代码坏味道与重构手法 | Martin Fowler《重构》 | 出书，两版跨 20 年 | 受版权保护 |
| 整洁代码 | Robert C. Martin《代码整洁之道》 | 出书 | 受版权保护 |
| 代码大全 | Steve McConnell《代码大全》 | 出书，两版 | 受版权保护 |
| 深模块、复杂度 | John Ousterhout《软件设计的哲学》 | 出书，课程使用 | 受版权保护 |
| 程序设计实践 | Kernighan、Pike《程序设计实践》 | 出书 | 受版权保护 |
| 修改遗留代码 | Michael Feathers《修改代码的艺术》 | 出书 | 受版权保护 |
| 代码评审实践 | [Google eng-practices](https://google.github.io/eng-practices/) | 机构发布，约 2.1 万星，2025-11 归档 | 开放（CC-BY 3.0） |
